# TrainingWeb - Personal Trainer Landing Page

Uma landing page moderna e responsiva focada na divulgação dos serviços de um Personal Trainer. O projeto foi desenvolvido visando alta performance, experiência de usuário (UX) premium e facilidade de manutenção.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

- **[React](https://reactjs.org/)** (via [Vite](https://vitejs.dev/)): Biblioteca JavaScript para construção da interface de usuário, garantindo um código modularizado e de alta performance.
- **[Tailwind CSS](https://tailwindcss.com/)**: Framework CSS utilitário para a criação de um design customizado, rápido e sem a necessidade de sair do arquivo JSX.
- **Ícones SVG**: Utilizados nativamente para manter a leveza do projeto e um carregamento rápido, sem depender de bibliotecas externas pesadas.

## ⚙️ Como Executar o Projeto

Siga os passos abaixo para rodar o projeto localmente na sua máquina:

### Pré-requisitos
- Ter o [Node.js](https://nodejs.org/) instalado.

### Passo a Passo

1. **Abra o terminal e acesse a pasta do projeto:**
   ```bash
   cd TrainingWeb
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   O terminal irá exibir um link (geralmente `http://localhost:5173`). Clique nele ou copie e cole no seu navegador para ver a página rodando.
